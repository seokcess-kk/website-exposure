> **상태**: v0.2 — 1차 분석 + 모범 의료기관 추가 분석 통합
> **작성일**: 2026-05-13 (v0.1 → v0.2 갱신)
> **소유자**: Glitzy
> **목적**: 실제 의료기관 웹사이트 6곳을 일관 프레임으로 분석하여, 솔루션의 기존 명세와 현실의 간극·차별화 기회·누락 항목을 도출한다. 1차(국내 한의원 4개) + 2차(국내 대형 의료기관·해외 모범 사이트)로 확장.

## 4. 핵심 발견 (1차 + 2차 통합)

### 4.1 보편적 약점 (모든 6개 사이트 공통)

| 약점 | 솔루션 차별화 기회 |
|---|---|
| JSON-LD Schema 전무 | Core 자동 생성 → 즉시 차별화 |
| 시맨틱 HTML 약함 | Core 강제 → 즉시 차별화 |
| 헤딩 위계 (한국 사이트) | Core 룰 강제 → 즉시 차별화 |
| FAQ 페이지 부재·약함 | FAQPage schema + Q&A 블록 표준 → 차별화 |
| 자체 콘텐츠 클러스터 약함 (외부 블로그 의존) | 자체 Articles + 내부 링크 누적 → 장기 차별화 |
| AEO 친화 콘텐츠 구조 부재 | CONTENT_STANDARDS 표준 → 차별화 |

### 4.2 모범 의료기관의 새 발견 (2차 분석 결과)

| 발견 | 시사점 |
|---|---|
| **위험도 표현 절제 = 권위 신호** | 1호 클라이언트 차별화 전략 핵심 — "대학병원 수준 엄격 표현" |
| **콘텐츠 IA가 정연·풍부** | 1호도 단순화 적용 가능 — Pillar 6~7개 |
| **콘텐츠 형식 3분리 (텍스트·영상·칼럼)** | Article에 `contentFormat` 필드 추가 권장 |
| **연구·미디어·인증·사회공헌 별도 노출** | About 슬롯에 명시 |
| **Cleveland 기술 SEO가 한국보다 발전** | H1·H2·H3 위계 명확. 모범 적용 가치 |
| **다국어는 서브도메인 분리가 보편** | M3 GA에서 도입 시 패턴 |

### 4.3 위험도 표현 — 업계 전체 패턴 분석

```
┌────────────────────┬─────────────────────┬──────────────────────┐
│  소형 한의원·클리닉   │  중대형 의료기관     │  대학병원·해외 모범    │
│  (R-A1·A2·A3)      │  (R-B1)             │  (R-B2·C1)           │
├────────────────────┼─────────────────────┼──────────────────────┤
│  위험도 표현 만연    │  부분적 사용         │  거의 없음             │
│  마케팅 톤 우선      │  마케팅 + 권위 혼재   │  권위·신뢰 위주        │
│  의료광고법 위반 소지 │  일부 회색지대      │  법적 안정             │
└────────────────────┴─────────────────────┴──────────────────────┘
```

→ **1호 클라이언트(다이어트 한의원)의 전략적 선택**:
- 옵션 A: 소형 한의원 관행 따라 위험도 표현 적극 사용 (단기 효과 ↑, 법적 리스크 ↑)
- 옵션 B: **대학병원 수준의 엄격한 표현 사용** (장기 신뢰도 ↑, 차별화 ↑, 단기 마케팅 효과 ↓)
- 솔루션 권장: **옵션 B** — VLM·AI 사이트 브리핑·통합 랭킹 모두에서 가점. 1호 클라이언트와 사전 합의 필수.
